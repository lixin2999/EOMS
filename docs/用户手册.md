# EOMS 企业运营管理系统 · 用户手册

> 适用版本：V1.0.0
> 适用对象：业务申请人、部门负责人、审批人、项目经理、财务、采购、审计与系统管理员。

---

## 1. 系统简介

EOMS 将「审批、项目、供应商与合同、成本与预算、经营报表」放在同一条数据链路上：

- 报销、请假、文件在审批通过后自动流转到业务状态，并与成本台账联动；
- 项目从立项、计划、执行、验收到归档全程留痕，进度与成本统一归集；
- 供应商、合同、付款、收款、计收、预算、财务期间共享同一套数据口径；
- 所有操作写入审计日志，敏感字段按权限脱敏展示。

系统菜单按账号拥有的权限动态显示。看不到某个菜单，说明当前角色没有该模块权限，请联系系统管理员调整角色。

### 1.1 业务角色

| 角色 | 典型岗位 | 数据范围 | 主要职责 |
| --- | --- | --- | --- |
| 系统管理员（ADMIN） | 系统管理员 | 全公司 | 用户、角色、部门、流程、参数、审计 |
| 董事（DIRECTOR） | 董事/总经理 | 全公司 | 全局查看、大额/长期/机密事项终审 |
| 经理（MANAGER） | 部门经理 | 本部门及下级 | 第二级审批、部门项目管理 |
| 部门负责人（DEPT_LEADER） | 主管/负责人 | 本部门 | 第一级审批、部门成本查看 |
| 项目经理（PM） | 项目经理 | 参与项目 | 项目全生命周期、WBS、任务、验收 |
| 财务专员（FINANCE） | 会计/财务 | 全公司 | 付款、收款、计收、预算、期间、报表 |
| 采购专员（PURCHASE） | 采购 | 全公司 | 供应商准入、合同、评价 |
| 审计（AUDITOR） | 内审 | 全公司 | 审计日志、单据与流程追溯 |
| 员工（EMPLOYEE） | 普通员工 | 仅本人 | 报销、请假、文件发起与本人单据 |

> 一个账号可以拥有多个角色，权限取并集，但始终收敛在公司边界内。

## 2. 登录与账号安全

### 2.1 登录

1. 浏览器打开系统地址（本地开发默认 `http://127.0.0.1:5180`，Docker 部署默认 `http://服务器地址`）。
2. 输入用户名、密码和图形验证码。
3. 点击「登录」，成功后进入工作台。

注意事项：

- 验证码一次性使用，有效期默认 120 秒，看不清可点击刷新。
- 连续登录失败 5 次，账号临时锁定 15 分钟；等待解锁或联系管理员。
- 同一账号最多保留 3 个并发会话，超出后最早的会话会失效。
- 密码默认 90 天有效期，建议到期前主动修改，避免因令牌或会话策略变化影响使用。
- 登录凭证保存在浏览器 HttpOnly Cookie 中（页面脚本不可读取），访问有效期 30 分钟；刷新凭证 3 天，过期需重新登录。

### 2.1.1 会话保持与重新登录

- 页面操作过程中访问凭证会自动续期，无需手动刷新。
- 若看到“登录已过期，请重新登录”或页面被跳回登录页，说明会话已过期、被其他设备挤占或凭证被安全策略收回，请直接重新登录。
- 若看到“会话刷新失败，请稍后重试”，表示刷新服务暂时异常，并不代表登录已过期；当前会话会保留，请稍后重试。若反复出现，请联系管理员检查服务状态。
- 在多个标签页同时操作时，若其中一个标签页已重新登录，其他标签页刷新即可继续使用。
- 写操作（新建/修改/删除/审批）依赖浏览器 Cookie 与页面令牌配合校验；若提示「CSRF 校验失败，请刷新页面重试」，刷新当前页面后重试即可。
- 不建议在同一浏览器手动清除单个 Cookie，否则会导致登录状态异常；如需清理请退出登录后重新登录。
- 从 V1.2.10 或更早版本升级后，若首次重新登录仍立即返回登录页，请由管理员确认已升级到 V1.2.11，并清除 `eoms_at`、`eoms_rt`、`eoms_csrf` 三个 Cookie 后重新登录。

### 2.2 首次登录强制改密

管理员新建用户或重置密码后，账号处于「首次登录」状态。登录后会自动跳转到修改密码页，必须修改密码才能进入业务页面。

密码规则：

- 长度 8–64 位；
- 大写字母、小写字母、数字、特殊字符四类中至少包含三类；
- 不得包含用户名；
- 不得使用常见弱密码。

### 2.3 修改密码与个人信息

- 右上角头像 →「修改密码」：输入原密码、新密码并确认。修改成功后需要重新登录。
- 右上角头像 →「个人信息」：查看姓名、账号、公司、部门、岗位、角色、邮箱和最近登录时间。

### 2.4 退出登录

右上角头像 →「退出登录」。在公共电脑使用后请务必退出。

| 区域 | 内容 |
| --- | --- |

## 5. 审批中心

审批中心包含费用报销、请假管理、文件审批、我的待办、流程实例五个页面。

### 5.1 通用审批规则

默认审批链按业务类型配置，节点条件不满足时自动跳过：

| 业务类型 | 默认审批链 |
| --- | --- |
| 费用报销（EXPENSE） | 部门负责人 → 部门经理 → 董事（金额 ≥ 50000 时触发） |
| 请假（LEAVE） | 部门负责人 → 部门经理 → 董事（天数 ≥ 5 时触发） |
| 文件审批（DOCUMENT） | 部门负责人 → 部门经理 → 董事（密级为「机密」时触发） |
| 项目立项（PROJECT_INITIATION） | 部门负责人 → 部门经理 → 董事 |
| 项目变更（PROJECT_CHANGE） | 部门负责人 → 部门经理 → 董事 |
| 项目验收（PROJECT_ACCEPTANCE） | 部门负责人 → 部门经理 |
| 供应商准入（VENDOR_ONBOARD） | 部门负责人 → 部门经理 |

审批动作说明：

| 动作 | 说明 |
| --- | --- |
| 同意 | 通过当前节点；会签节点需全部同意 |
| 驳回 | 必须填写驳回原因，流程退回发起人 |
| 转办 | 将当前任务转给其他处理人 |
| 加签 | 在当前节点增加审批人 |
| 催办 | 提醒当前处理人尽快处理 |
| 抄送 | 将流程知会相关人员，不参与审批 |
| 撤回 | 发起人可在流程结束前撤回 |

节点默认处理时限 24 小时，超时任务在「我的待办」中标记为超时。

### 5.2 费用报销

**发起报销**

1. 进入「审批中心 → 费用报销」，点击「新建报销」。
2. 选择所属项目、报销类型（差旅费、业务招待费、办公费、分包费、材料费、其他）、币种，填写收款人与备注。
3. 添加费用明细：科目、金额、发生日期、说明。明细至少 1 条、最多 100 条，合计金额必须大于 0。
4. 上传发票附件（提交前必填）。
5. 选择「保存草稿」或「保存并提交」。

**提交校验**

- 只能提交本人单据（超级管理员除外）；
- 必须有发票附件和归属项目；
- 项目不能处于「已关闭 / 已取消 / 已归档」状态；
- 费用发生期间不能已关账；
- 草稿或已驳回状态才可提交。

**状态流转**

```
草稿 DRAFT → 审批中 RUNNING → 已通过 APPROVED → 已复核 VERIFIED → 已付款 PAID → 已归档 ARCHIVED
                  ↓
              已驳回 REJECTED（可修改后重新提交）
草稿 → 已取消 CANCELED
```

**后续操作**

- 审批中可「撤回审批」；草稿可「取消单据」。
- 审批通过后，财务在详情中点击「财务复核」。
- 复核通过后点击「前往付款」进入付款管理，为该报销单创建付款单。
- 付款完成后回到报销详情点击「归档」。
- 审批通过时系统自动把报销金额计入项目成本；付款执行后登记资金流出日期。

### 5.3 请假管理

**发起请假**

1. 进入「审批中心 → 请假管理」，点击「发起请假」。
2. 选择请假类型：年假、事假、病假、调休。
3. 选择起止时间，填写请假时长（最小精度 0.5 天，单次不超过 365 天）。
4. 可选择交接人（不能是本人）。
5. 填写请假事由后保存或提交。

**校验规则**

- 结束时间必须晚于开始时间；
- 同一时间段不能存在重复请假；
- 年假、调休提交时校验可用余额，余额不足不能提交；
- 页面顶部展示各类假期余额（年度额度、已使用、剩余）。

审批通过后自动扣减年假/调休余额，单据状态变为「已通过」。

### 5.4 文件审批

适用于制度文件、通知公告、用印申请、合同文本。

1. 进入「审批中心 → 文件审批」，点击「新建文件」。
2. 填写标题、文号、分类、密级（公开/内部/机密）和正文。
3. 用印申请、合同文本必须上传文件附件。
4. 保存或提交审批。

密级为「机密」时会触发董事终审。文件按密级控制可见范围，审批记录完整保留。

**密级可见性**：

- 公开 `PUBLIC`、内部 `INTERNAL` 文件对公司内有权限的人员可见；
- 机密 `SECRET` 文件仅超管与**创建人本人**可见，其他人员（含审批人）在列表与详情中均不可见；
- 需要他人审批的机密文件，建议先提交非密事项，正文与附件走线下或专用保密渠道，避免审批人无法打开单据；
- 如确有必要让审批人看到正文，可先将密级调整为「内部」再提交。

### 5.5 我的待办

- 默认展示「我的任务」，可切换查看全部任务。
- 统计卡片显示我的待办数量、超时任务数量。
- 可按流程状态、业务类型、关键词筛选。
- 点击任务打开审批面板，查看流程节点、当前处理人、流转记录，并执行同意、驳回、转办、加签、催办、抄送。

### 5.6 流程实例

用于查看所有审批流程的全貌：

- 按流程状态（审批中、已通过、已驳回、已撤回、已取消）、业务类型筛选；
- 可勾选「仅我发起」；
- 支持按流程标题或发起人搜索；
- 详情可查看节点进度、处理人、处理意见、抄送人，并可催办、撤回、抄送。

## 6. 项目管理

### 6.1 项目列表

进入「项目管理」，页面展示项目总数、执行中数量、合同总额等统计。

- 「新建项目」：直接创建项目主档（草稿）。
- 「发起立项」：创建项目并发起立项审批，审批通过后项目进入「立项」阶段并生效。

列表支持按项目名称、编号、阶段、状态、项目经理等筛选。

### 6.2 项目阶段与状态

**阶段**：立项 `LAUNCH` → 计划 `PLAN` → 计划已确认 `PLAN_CONFIRMED` → 执行 `EXECUTE` → 收尾 `CLOSE` → 已归档 `ARCHIVED`

**状态**：草稿 `DRAFT`、待审批 `PENDING`、生效 `ACTIVE`、已暂停 `SUSPENDED`、已关闭 `CLOSED`、已取消 `CANCELED`、已归档 `ARCHIVED`

### 6.3 项目详情

项目详情包含以下页签：

| 页签 | 内容 |
| --- | --- |
| 概览 | 项目基本信息、描述、进度与偏差、预算/合同/成本概况 |
| 损益 | 项目收入、成本、毛利与损益快照 |
| 立项 | 立项申请信息与审批状态 |
| 成员 | 项目经理、成员、观察者及角色 |
| WBS | 工作分解结构、层级、负责人、计划日期、进度 |
| 任务 | 任务状态、优先级、负责人、计划/实际时间、工时、进度 |
| 里程碑 | 计划日期、实际完成日期、验收文件 |
| 变更 | 范围/进度/预算变更及审批记录 |
| 问题与风险 | 等级、负责人、截止日期、状态、解决方案 |
| 周报 | 项目周报记录 |
| 验收 | 验收人、结果、日期、金额、附件 |
| 归档 | 立项、合同、验收、结算、总结等归档资料 |
| 基线 | 计划确认后生成的基线版本 |

**阶段操作**

1. 计划编制完成后，点击「确认计划并生成基线」。
2. 计划确认后，点击「进入执行阶段」。
3. 项目满足关闭条件后，点击「关闭项目」。
4. 项目关闭且至少有一条归档资料后，点击「归档项目」。

**项目关闭校验（5 项）**

- 不存在未完成任务；
- 不存在待付款的付款单；
- 最新验收申请已审批通过；
- 验收单已上传签署文件，并已归档到项目档案；
- 不存在未关闭问题。

不满足时可申请「强制关闭」，需要 `project:force-close` 权限，且关闭原因不少于 5 个字。

**验收**

- 只有进行中的项目可提交验收；
- 验收结果分为通过、有条件通过、未通过；
- 必须填写验收人并上传验收签署文件；
- 验收通过后按验收金额自动生成计收（金额大于 0 时）。

**归档类型**：立项资料、合同文本、验收单、结算资料、复盘总结、其他资料。

### 6.4 项目变更

项目处于可变更状态时可发起变更：

- 变更类型：范围变更、进度变更、预算变更；
- 变更原因不少于 5 个字；
- 按变更类型填写变更后内容（名称/描述、预算、计划起止日期）；
- 变更提交后进入审批，审批通过后写回项目主档。

## 7. 供应商与合同

### 7.1 供应商管理

**新建供应商**

1. 进入「供应商管理」，点击「新建供应商」。
2. 填写名称、分类（劳务分包、材料供应、技术服务、设备租赁）、负责人、简介等信息。
3. 保存后状态为「待准入」。

**供应商详情页签**

| 页签 | 内容 |
| --- | --- |
| 概览 | 基本信息、合作概况、待关注资质 |
| 联系人 | 姓名、电话、邮箱、职务 |
| 银行账户 | 开户行、账号、户名 |
| 资质证照 | 证照名称、编号、有效期、附件 |
| 合作项目 | 关联项目及合作金额 |
| 合同 | 关联合同与状态 |
| 评价 | 质量、进度、配合评分与等级 |
| 年度评价报告 | 年度综合表现 |

**准入与状态**

- 待准入供应商提交准入审批，审批通过后变为「合作中」；
- 可暂停、恢复或加入黑名单；
- 黑名单供应商不能修改、不能签订合同、不能付款；
- 解除黑名单后恢复为可合作状态。

**评价规则**

- 质量 40% + 进度 30% + 配合 30%；
- 综合分 ≥ 90 为 A 级，≥ 75 为 B 级，< 75 为 C 级；
- 供应商综合分取历史评价均值，并同步更新供应商等级；
- 黑名单供应商不能评价。

### 7.2 合同管理

**新建合同**

1. 进入「合同管理」，点击「新建合同」。
2. 选择供应商、关联项目，填写合同名称、编号、金额、签订日期、起止日期、付款条款。
3. 保存后为「草稿」，确认无误后「置为生效」。

**状态**：草稿 `DRAFT`、生效中 `ACTIVE`、已到期 `EXPIRED`、已终止 `TERMINATED`。

**合同详情页签**：合同信息、付款条款、付款记录。

**风险提示**

- 合同 45 天内到期或已超付时，工作台与合同列表给出风险提醒；
- 到期合同可手动「标记到期」，系统定时任务也会自动置为已到期；
- 生效合同可「终止合同」，终止后不能继续付款；
- 黑名单供应商不能签订合同。

**发起付款**：合同详情右上角「发起付款」直接进入付款创建流程，合同与供应商自动带出。

## 8. 财务管理

### 8.1 成本台账

展示所有成本流水，支持按项目、科目、业务类型、期间、状态筛选。

- 业务类型：计收、收款、付款、报销；
- 成本记录状态：有效 `ACTIVE`、已冲销 `REVERSED`；
- 冲销记录以负数展示，并保留原记录关联；
- 财务期间关账后禁止写入成本数据。

**关账后的待补记成本**

- 期间已关账时，报销审批、验收自动计收仍可正常完成，但成本不会直接入账，而是进入「待补记」暂存（页面提示「期间已关账，成本已暂存」并通知财务）；
- 财务反关账后系统会自动补记；也可以由定时任务（默认每 10 分钟）对已开账的期间自动补记；
- 财务可在「待补记成本」视图中查看数量、金额与所属期间，择机开账处理；
- 付款动作不做暂存：期间关账时仍会直接拦截，需先反关账。

### 8.2 付款管理

**付款类型**

- 供应商/合同付款；
- 报销单付款。

**新建付款**

1. 进入「付款管理」，点击「新建付款单」。
2. 选择付款类型：
   - 供应商付款：选择供应商、关联合同，填写付款金额、付款方式、计划付款日期；
   - 报销付款：选择已审批通过的报销单，付款金额自动等于报销单金额。
3. 保存后付款单状态为「待付款」。
4. 执行付款后状态变为「已付款」，同时写入成本台账与资金日期。

**校验规则**

- 付款金额必须大于 0；
- 报销付款必须一单一付，金额必须等于报销单金额；
- 报销单必须处于「已通过」或「已复核」状态；
- 黑名单供应商禁止付款；
- 项目已关闭或已归档时不能新增付款；
- 超合同金额只预警、不阻断付款。

**状态**：待付款 `PENDING`、已付款 `PAID`、已取消 `CANCELED`。

### 8.3 收款管理

1. 进入「收款管理」，点击「登记收款」。
2. 选择项目、客户、关联合同，填写收款金额、收款日期、收款方式。
3. 保存后状态为「已登记」。

- 收款金额必须大于 0；
- 作废收款会生成冲销成本记录；
- 收款用于现金流量表与应收账款分析。

**状态**：已登记 `REGISTERED`、已取消 `CANCELED`。

### 8.4 计收确认

1. 进入「计收确认」，点击「新增计收」。
2. 选择项目、客户、关联合同，填写计收金额、确认日期。
3. 保存为草稿，确认后写入收入台账（6001 主营业务收入）。

- 计收金额必须大于 0；
- 项目已关闭或已归档时不能新增计收；
- 仅草稿状态可确认；
- 取消已确认计收会生成冲销记录；
- 项目验收通过且金额大于 0 时，系统自动生成计收。

**状态**：草稿 `DRAFT`、已确认 `CONFIRMED`、已取消 `CANCELED`。

### 8.5 预算管理

按「项目 + 成本科目 + 年度」维护预算：

1. 先选择项目和年度。
2. 点击「新增预算」，选择成本科目，填写年度预算金额和备注。
3. 列表展示年度预算、实际成本、执行率与进度条。
4. 实际成本按有效成本记录累计。

- 执行率达到预警阈值（默认 90%）时，页面提示预警并生成通知；
- 执行率超过 100% 标记为「已超预算」；
- 可调整或删除预算；
- 已关闭、已归档项目不能维护预算。

### 8.6 财务期间

- 每个会计期间状态为「开放 `OPEN`」或「已关账 `CLOSED`」。
- 点击「关账」并填写备注后，该期间不能再写入成本数据，同时为有成本记录的项目生成损益快照。
- 已关账期间可「反关账」，必须填写不少于 3 个字的原因。
- 关账前请确认当月报销、付款、收款、计收均已处理完毕。

## 9. 报表中心

报表中心提供七类报表，支持在线查看、Excel/PDF 导出和报表快照。

| 报表 | 说明 |
| --- | --- |
| 经营总览 | 确认营收、总成本、毛利/毛利率、项目数量、收款、应收/应付余额、现金净额、月度趋势 |
| 营收报表 | 按期间/项目/客户统计确认营收 |
| 现金流量表 | 收款减去已付款（付款 + 报销）的现金净额 |
| 利润表 | 收入、成本、毛利与毛利率 |
| 项目损益表 | 单项目收入、成本、毛利，取区间内最新损益快照 |
| 供应商支出分析 | 按供应商/合同统计付款与支出占比 |
| 审批效率报表 | 流程数量、平均处理时长、超时与节点效率 |

口径说明：

- 成本口径为「付款 + 报销」；
- 营收以「已确认计收」为准，草稿计收不进入报表；
- 现金流为「收款 −（已付款 PAYMENT + 已付款 EXPENSE）」；
- 项目损益优先取财务期间关账生成的快照。

操作：

- 顶部切换报表类型；
- 选择期间、项目、供应商等筛选条件后点击「查询」；
- 「导出 Excel」「导出 PDF」下载当前筛选结果；
- 「生成快照」保存当前报表口径，供后续对比与留档。

## 10. 系统管理

> 以下页面通常仅系统管理员可见，部分页面按权限开放给审计或业务管理员。

### 10.1 用户管理（账号开通）

- 新建用户：用户名、姓名、初始密码、部门、岗位、手机号、邮箱、角色、状态、是否首次登录。
- 初始密码可一键「随机」生成（自动包含大写、小写、数字、符号四类）并「复制」发送给用户。
- 编辑用户：修改姓名、部门、岗位、联系方式、角色、状态；部门/岗位/联系方式清空后即解除原归属。
- 列表「状态」开关可直接启用/停用账号，即时生效；不能停用当前登录账号。
- 重置密码：重置后用户下次登录必须修改密码。
- 停用用户：停用后无法登录，历史数据保留。
- 手机号等敏感字段按权限脱敏展示。

### 10.2 角色权限

- 左侧角色列表展示编码、名称、数据域、权限数、是否内置。
- 新建/编辑角色：编码、名称、数据域、状态、备注。
- 右侧权限树按菜单/接口勾选权限。
- 内置角色不可删除；自定义角色可删除。

**数据域**：全公司 `ALL`、本公司 `COMPANY`、部门及下级 `DEPT_TREE`、本部门 `DEPT`、参与项目 `PROJECT`、仅本人 `SELF`。

### 10.3 组织架构

- 树形展示部门层级，支持新增根部门、新增子部门、编辑、停用、删除。
- 维护部门名称、编码、排序、上级部门、部门负责人。
- 删除部门前需先处理下级：仍存在子部门或仍有用户归属时不允许删除，提示具体数量。
- 部门负责人是审批链「部门负责人」节点的实际处理人来源。

### 10.4 审批流程配置

- 列表展示业务编码、流程名称、当前版本、节点数、流程预览、状态、更新时间。
- 「内置模板」可查看系统预置流程，选择模板后打开编辑器并自动生成新版本。
- 编辑流程：
  - 基本信息：业务编码、流程名称、启用状态、备注、编辑方式；
  - 全局设置：驳回后回退方式（发起人/上一节点）、超时小时数、允许撤回、允许转办、允许加签；
  - 审批节点：审批人类型（指定用户、指定角色、部门负责人、项目经理、发起人上级）、审批模式（或签/会签）、金额上下限、天数下限；
  - 节点可上移、下移、删除，条件不满足时自动跳过。
- 「版本」查看历史版本，可选择「基于此版本编辑」。
- 同一业务编码保存后生成新版本，旧版本保留可追溯。

### 10.5 审计日志

- 按时间、操作人、动作、业务对象、IP、trace_id 筛选。
- 展开行可查看字段级变更前后对比。
- 用于安全审计、问题追溯和责任认定。

### 10.6 系统参数

包含三个页签：

| 页签 | 内容 |
| --- | --- |
| 数据字典 | 维护业务字典项（类型、标签、值、排序、状态、备注） |
| 系统参数 | 维护键值型参数与说明 |
| 客户主档 | 维护客户名称、编号、联系人、电话、邮箱、地址、状态 |

### 10.7 修改密码

- 入口：系统管理 →「修改密码」，或右上角头像 →「修改密码」。
- 填写原密码、新密码并确认，密码需至少 8 位且包含大小写、数字、符号中的三类，且不得与原密码相同。
- 修改成功后当前会话与其他设备登录状态一并失效，需使用新密码重新登录。

## 11. 通知与文件

### 11.1 通知

顶部铃铛展示未读数量，点击打开通知列表：

- 审批通知：待办到达、审批结果；
- 预警通知：预算阈值、合同到期、供应商资质到期、超付；
- 系统通知：其他系统消息。

支持「全部已读」和「查看」跳转到关联单据。

### 11.2 文件上传与下载

- 表单中的上传控件支持选择文件、重新上传、下载、移除；
- 单文件默认上限 30MB（可通过 `EOMS_MAX_UPLOAD_MB` 调整，Nginx 限制 32MB）；
- 文件按公司、年月、哈希存储，自动去重；
- 下载权限与业务单据权限一致，无权访问时提示文件不存在或无权访问。

## 12. 常见错误与处理

| 提示/现象 | 原因 | 处理 |
| --- | --- | --- |
| 用户名或密码错误 | 输入错误 | 核对账号密码，注意大小写 |
| 验证码错误或已过期 | 验证码超时或已使用 | 刷新验证码后重试 |
| 登录失败次数过多，账号已临时锁定 | 连续失败 5 次 | 等待 15 分钟或联系管理员 |
| 首次登录被要求改密 | 账号处于首次登录状态 | 按提示修改密码后进入系统 |
| 您没有访问该页面的权限 | 角色缺少菜单权限 | 联系管理员调整角色 |
| 请上传发票附件后再提交 | 报销缺少发票 | 上传发票后重新提交 |
| 项目已关闭，不能提交报销 | 项目状态为关闭/取消/归档 | 更换项目或联系项目经理 |
| 期间已关账，禁止写入成本数据 | 财务期间已关账 | 付款类操作请财务反关账后重试；报销/计收会自动转为「待补记」 |
| 期间已关账，成本已暂存 | 报销审批或验收计收时期间已关账 | 无需处理，联系财务开账后系统自动补记 |
| 登录已失效，请重新登录 | 会话过期、多设备挤占或刷新凭证被重放检测拦截 | 直接重新登录；反复出现联系管理员 |
| 会话刷新失败，请稍后重试 | 刷新接口参数校验、服务端或网络异常，不代表登录已过期 | 当前会话会保留，稍后重试；反复出现时联系管理员检查服务状态 |
| CSRF 校验失败，请刷新页面重试 | 浏览器 Cookie 与页面令牌不一致（页面停留过久） | 刷新页面后重试 |
| 文件不存在或无权访问 | 文件为「机密」且非本人创建 | 由创建人调整密级或转交原件 |
| 该部门下还有 N 个子部门/用户 | 删除部门时仍有下级或成员 | 先删除/迁移子部门，或把用户调整到其他部门后再删除 |
| 可用假期余额不足 | 年假/调休余额不够 | 调整请假类型或时长 |
| 该时间段已有请假记录 | 时间重叠 | 修改起止时间 |
| 请填写验收人 / 请上传验收签署文件 | 验收信息不完整 | 补全后重新提交 |
| 存在未完成任务/未结清付款/未关闭问题 | 项目关闭校验未通过 | 处理阻塞项或申请强制关闭 |
| 黑名单供应商禁止付款 | 供应商在黑名单 | 解除黑名单或更换供应商 |
| 该报销单已存在付款单 | 重复付款 | 一单一付，不能重复创建 |
| 文件超过 30MB 限制 | 文件过大 | 压缩或拆分后上传 |
| 页面 401 循环 | 令牌失效或时间不一致 | 清除浏览器本地存储后重新登录，检查服务器时间 |
